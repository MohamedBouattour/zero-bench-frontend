# 🏛️ Bug Fix Plan: Flash of Inaccurate Theme (FOIT/FOUC) Elimination

- **Timestamp:** 16_09_2026-23_20
- **Project:** BenchZero (ESN ERP)
- **Objective:** Eliminate the initial white/light flash on page load/reload when dark theme is active.

---

## 🔍 Root Cause Analysis
1. `src/index.html` loads without the `.dark` class on `<html>`.
2. Browser performs first paint using default light theme background (`#f8f9ff`).
3. Angular loads, hydrates, boots `ThemeStore`, and asynchronously adds `.dark` to `<html>` seconds later.
4. Because `body` has `transition-colors duration-200`, the page animates from light to dark on reload.

---

## 🛠️ Solution Architecture
1. **Synchronous `<head>` Anti-Flash Script (`src/index.html`):**
   - Inject an inline script at the top of `<head>` before any CSS/fonts.
   - Immediately inspects `localStorage.getItem('zero_bench_theme')` and `window.matchMedia('(prefers-color-scheme: dark)')`.
   - Synchronously adds `.dark` and sets `style.colorScheme = 'dark'` on `document.documentElement` before the browser parses `<body>` or paints the first frame.
2. **Root Canvas Dark Background (`src/styles.css`):**
   - Explicitly define `html.dark { background-color: #020617; color-scheme: dark; }` and `html:not(.dark) { background-color: #f8f9ff; color-scheme: light; }`.
3. **ThemeStore Synchronization (`src/app/core/stores/theme.store.ts`):**
   - Check `document.documentElement.classList.contains('dark')` during `getInitialTheme()`.
   - Update `colorScheme` property and persist to both `localStorage` and `document.cookie`.
