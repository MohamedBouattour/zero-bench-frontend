## ⚙️ 3. Execution Pipeline

1. **Local Preparation:**
   - Write `mock-server/package.json`.
   - Create `scripts/deploy-mock.sh` with robust error handling and verification.
2. **Remote Provisioning:**
   - Create `/var/www/zero-bench/mock-server` on VPS.
   - Synchronize code and seed datasets via `rsync`.
   - Install production dependencies via `npm install --omit=dev`.
3. **PM2 Daemon Management:**
   - If `zero-bench-mock` is running, perform `pm2 restart zero-bench-mock --update-env`.
   - If not, start with `pm2 start server.mjs --name zero-bench-mock --time`.
   - Execute `pm2 save`.
4. **Nginx Reverse Proxy Configuration:**
   - Safely append `/zero-bench/` static location and `/zero-bench/api/` proxy block to `/etc/nginx/sites-available/wall-street.cloud`.
   - Test configuration via `nginx -t`.
   - Graceful reload via `systemctl reload nginx`.
5. **Firewall (UFW):**
   - Enable `3001/tcp` in UFW for optional direct external access.
