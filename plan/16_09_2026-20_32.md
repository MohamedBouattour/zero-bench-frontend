- **Timestamp:** 16_09_2026-20_32
- **Project:** BenchZero (ESN Operations Suite / ERP)
- **Stitch Design System Reference:** [Project 15147121731840790718](https://stitch.withgoogle.com/u/1/projects/15147121731840790718?pli=1)
- **Framework:** Angular 21 LTS (Zoneless + SSR + Standalone + Native Signals)
- **Styling:** Tailwind CSS (Dark/Light mode, Stitch Design Tokens)
- **Dependencies:** 0 third-party UI libraries (pure native Angular + Tailwind CSS)

---

## 1. Executive Summary & Goals

Initialize and scaffold **BenchZero**, an enterprise ESN (Entreprise de Services Numériques) resource planning and inter-contrat risk management application. The project is scaffolded using Angular 21 LTS in **zoneless** mode with **SSR** capabilities, powered by pure native **Signals State Management** without external third-party state or component libraries.

The application adheres strictly to:
1. **Domain-Driven Design (DDD)** modularity.
2. The user's architectural rule for shared layout utilities in `/src/app/core/components/` and domain widgets in `/src/app/core/widgets/`.
3. Stitch Design System tokens (Navy, Electric Blue, Semantic status emerald/amber/red, and Indigo AI glassmorphism).
4. Full Dark / Light theme responsiveness and Multi-language (EN/FR) support with native Signals.
5. Workspace AI Skill files (`.agents/skills/zero-bench-dev/SKILL.md`) and deployment pipeline (`deploy.sh`).

---

## 2. Technology Stack & Architectural Decisions

| Layer | Technology | Rationale |
| :--- | :--- | :--- |
| **Framework** | Angular 21 (LTS) Standalone | Modern Angular standard, eliminating NgModules |
| **Change Detection** | Zoneless (`provideZonelessChangeDetection`) | Maximum runtime performance, zero `zone.js` overhead |
| **Rendering** | Angular SSR (`@angular/ssr`) | Server-side rendering & static hydration |
| **Styling** | Tailwind CSS + CSS Variables | Pixel-accurate Stitch design system tokens, seamless dark mode |
| **State Management** | Angular Signals (`signal`, `computed`, `effect`) | Native reactive primitives, zero third-party dependencies |
| **Icons** | Material Symbols Outlined (Web font / SVG) | Stitch design fidelity |
| **Architecture** | Domain-Driven Design (DDD) | Decoupled domain features with shared core utilities |

## 5. Implementation Phases

### Phase 1: Workspace Bootstrapping
1. Run `ng new zero-bench --directory=. --ssr --zoneless --routing --style tailwind --package-manager npm --strict --interactive=false`.
2. Configure `tailwind.config.js` with Stitch palette, dark mode `class` strategy, font family `Inter`, and radius tokens.
3. Configure `src/index.html` with Inter and Material Symbols Outlined fonts.
4. Set up SSR-safe utilities and verify server build.

### Phase 2: Core State Stores (Pure Signals)
1. `ThemeStore`: Signals for `'light' | 'dark'`, sync with `localStorage` (guarded by `isPlatformBrowser`), toggles `.dark` class on root HTML.
2. `LanguageStore`: Signals for `'en' | 'fr'`, provides reactive translated strings for navigation, headers, and actions without external i18n packages.
3. `NavigationStore`: Signals for sidebar collapse, active menu route, mobile navigation state.

### Phase 3: Core Shared Components & Widgets
1. Implement `/src/app/core/widgets/`:
   - `lang-selector.component.ts`
   - `theme-toggle.component.ts`
   - `status-badge.component.ts`
   - `stat-card.component.ts`
   - `ai-sparkle-card.component.ts`
   - `data-table-container.component.ts`
2. Implement `/src/app/core/components/`:
   - `sidebar.component.ts` (matching Stitch menu layout: Core Intelligence & Administration sections)
   - `header.component.ts` (Search bar, theme switcher, lang selector, notification badge, user profile)
   - `breadcrumbs.component.ts`
   - `layout.component.ts` (main content wrapper with responsive drawer)

### Phase 4: DDD Domain Scaffolding & Routing
1. Scaffold empty domain components with clean title, description, and preview placeholder layout:
   - `/` & `/dashboard`: Bench Risk Dashboard
   - `/skills-gap`: Skills Gap Heatmap
   - `/placements`: Placement Pipeline
   - `/pitch-generator`: AI Pitch Generator
   - `/consultants`: Consultants Directory
   - `/clients`: Clients & Missions
   - `/design-system`: Design System Showcase
2. Configure lazy-loaded standalone routes in `src/app/app.routes.ts`.

### Phase 5: AI Skills, Documentation & DevOps
1. Create `.agents/skills/zero-bench-dev/SKILL.md` (detailed workflow guide).
2. Create `deploy.sh` script complying with Protocol section 6.
3. Create a clean, production-grade `README.md`.
