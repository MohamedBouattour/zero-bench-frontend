# 🏛️ Modernization & Feature Completion Plan

- **Timestamp:** 16_09_2026-23_23
- **Project:** BenchZero (ESN ERP)
- **Objective:**
  1. Modernize every component: drop `CommonModule` / `NgClass`, drop redundant `standalone: true`, `OnPush`, `[class]` bindings, `computed()` instead of template method calls, `toSignal()` instead of manual subscriptions, `host` listeners.
  2. Complete every scaffolded / dead feature found in the scan (buttons with no handler, `alert()`, hardcoded mock data inside `src/`).
  3. Extend the mock server + proxy with every endpoint these features need.
  4. Fix prerender bug: build-time API responses were baked into `ng-state` transfer cache → stale dashboards on reload.

---

## 🔍 1. Scan Findings

| Area | Finding | Resolution |
| :--- | :--- | :--- |
| All components | `CommonModule` + `NgClass`, method calls in templates, `standalone: true` | `[class]` + `computed()`, OnPush |
| SSR / Prerender | Stores fetch during prerender → transfer cache freezes build-time data | Stores fetch in browser only; initial `isLoading: true` renders skeletons server-side |
| Sidebar | `alert()` for Add Consultant, hardcoded badge `3` | Route to `/consultants?mode=new`, badges from `/api/navigation/badges` |
| Header | Search does nothing, bell does nothing, hardcoded user | Global search → `/consultants?q=`, notifications dropdown, `/api/me` |
| Lang selector | Dropdown never closes on outside click / Escape | `host` document listeners |
| Consultants | View / edit buttons dead, add = toast only | Detail modal, create/edit form modal, delete, sort, CSV export, URL deep links |
| Dashboard | Export / period / Match RFPs / AI card dead, AI card hardcoded, metrics preformatted strings | Live computed metrics, period switch, CSV export, AI recommendation from API, consultant modal |
| Clients | Add / Manage Missions dead, no KPIs, text loader | Client form modal, account detail modal (missions + RFPs), KPIs, search, skeleton |
| Placements | Static columns, New Opportunity dead | Drag & drop kanban, stage moves, create/edit/delete, stage history, signed → consultant on mission |
| Pitch generator | 100% hardcoded (policy violation), generate does nothing | Store + API, live consultants/RFPs, tone/language, copy, mailto, save to pipeline |
| Skills gap | Static text placeholder | Live heatmap, category filters, KPIs, skill detail modal, upskilling suggestions |
| Mock server | Mutates seed JSON on POST, no latency, few endpoints | In-memory DB, `MOCK_LATENCY`, full CRUD + derived analytics |
